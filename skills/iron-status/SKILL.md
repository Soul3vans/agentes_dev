# IRON Status

Manage the short living summary of the project.

## Hard rules

- Only Tech-Lead may update the file.
- The file must remain short and never exceed the context window.
- Details of debt and bugs live in docs/debt.md and docs/bugs.md (sources of truth).
- Never invent status, findings or decisions.

## Allowed actions

- Read the current 00-status.md.
- Propose a minimal update (summary only) for Tech-Lead to confirm.
- Highlight open blockers and deferred findings.

## Forbidden

- Writing long narratives.
- Duplicating full content from docs/debt.md or docs/bugs.md.
- Updating the file if you are not acting as Tech-Lead.
